Perceptual Imperceptibility: Why it looks identical to the naked eye
Should it be visible to the naked eye? No. Both layers are engineered to stay below the human visual system’s Just-Noticeable Difference (JND) threshold:
• 2-Bit RGB LSB Steganography: Modifies only the lowest 2 binary bits of each 0–255 color channel (Δ ≤ 3/255, ~1.1% luminance shift, >48 dB PSNR). To human photoreceptors it looks identical to the original; switch to 2-Bit LSB (×85) or PGD Heatmap |A-B| on the right to amplify those bits into plain view.
• AI-Blocking (PGD Latent Defense): Bound by an L∞ perceptual mask concentrated along high-frequency Sobel edges where human eyes cannot distinguish micro-gradients, while latent encoders amplify them into representation collapse.

Hardware, Telemetry & Thresholds
Compute Acceleration Backend i Selects hardware execution target. CUDA uses NVIDIA Tensor/FP16 cores. CPU mode is supported as a fallback but will be considerably slower.
▲ Non-CUDA compute backend selected. Iterative adversarial optimization on CPU or fallback drivers will run considerably slower than NVIDIA CUDA acceleration.
Telemetry Refresh Interval (ms) i Controls how frequently system sensors and graphs poll hardware (in milliseconds).
Working Proxy Grid Resolution (px) i Internal VAE latent grid dimension before bicubic perturbation upsampling to native resolution.
Floating-Point Compute Precision i FP16 halves VRAM consumption and doubles throughput on CUDA GPUs.
VRAM Warning Headroom (MB) i Minimum free GPU memory threshold before terminal emits low-VRAM headroom warnings.
Persistent Thermal Warning (°C) ▲ i Triggers a yellow warning triangle when hardware temperature stays above this threshold across consecutive checks.
Persistent Thermal Critical (°C) ▲ i Triggers a red thermal-throttling alert when hardware temperature stays above this critical threshold.
JPEG Export Quality (4:4:4) i Export compression quality with chroma subsampling disabled (4:4:4) so high-frequency defense perturbations are preserved.
Protection Compatibility Filter i Photo-Compatible Defenses Only hides in-generation-only or generator-side watermarking algorithms from the Workspace selector.
Native Resolution Policy i Controls how high-resolution photos are optimized and blended back onto the native-resolution image canvas.
Expectation Over Transformation (EOT) i Applies differentiable resize/crop/quantization transforms during optimization to harden perturbations against post-processing.
Auto-Load Paper Hyperparameters i Automatically snaps Perturbation Budget and algorithm-specific parameters to the published paper defaults when selecting a defense algorithm.
Allow System RAM Spillover (VRAM Offload) i Streams intermediate VAE forward activations to pinned System RAM (save_on_cpu) and enables tiled VAE encoding so 8 GB+ algorithms and native-resolution tiles run on lower-VRAM GPUs at reduced speed.
